# GoldenPassport 0.2.0 内测说明

感谢帮忙测试！0.2.0 是原生重写版：Apple Silicon 原生运行（也支持 Intel），需要 macOS 13 及以上。
你现有的 MFA 记录会自动迁移，旧版的数据文件不会被修改，随时可以回退。

## 安装

1. 解压收到的 zip，得到一个文件夹，里面有 `GoldenPassport.app`、`install.sh`、`rollback.sh` 和本说明。
2. 打开「终端」，输入 `bash `（注意后面有空格），把 `install.sh` 拖进终端窗口，按回车。
3. 脚本会依次完成下面这些步骤，每一步都会打印结果：
   - 检查安装包是否完整，以及是否支持你的 Mac；
   - 把当前的 App 和数据备份到 `~/GoldenPassport-backups/<时间>/`；
   - 退出旧版，安装新版到 `/Applications/GoldenPassport.app`；
   - 迁移数据，并和旧数据逐条核对。如果核对不通过，会**自动恢复**到安装前的状态；
   - 启动新版。

> 不需要在「系统设置」里点「仍要打开」，安装脚本已经处理好了。
> 请不要直接双击 zip 里的 App 运行，也不要手动拖进「应用程序」，否则可能会被系统拦截，也不会有备份。

## 安装后需要知道的变化

- **全局快捷键默认是 ⌃⌥⌘0–9**（旧版是 ⇧⌘0–9，会和截图快捷键冲突）。在菜单「全局快捷键（自动填入第 1–10 条）」里可以切换回 ⇧⌘。
- **自动填入需要重新授权「辅助功能」**：系统设置 → 隐私与安全性 → 辅助功能。
  如果列表里已经有 GoldenPassport，但按快捷键不会自动填入：先用「−」把它删掉，再到菜单里重新选一次快捷键，系统就会重新请求授权。
  没授权时，验证码会复制到剪贴板。

## 请帮忙验证

请把结果按编号回复给我，正常的写 ✅，有问题的写 ❌ 并简单描述现象：

1. 安装脚本最后显示「安装完成」，记录数和你原来的一致。
2. 菜单里所有记录的验证码都正常，随便挑一个网站登录试一下。
3. 添加一条记录（从二维码图片识别，或者粘贴 otpauth 链接）。
4. 打开「管理（排序 / 重命名）...」：拖动排序、重命名，然后看菜单里有没有跟着变化。
5. 按全局快捷键（⌃⌥⌘0 是第一条），验证码能复制到剪贴板。授权辅助功能之后，能自动填入。
6. 导出（`.secrets` 或 `.txt`），然后再导入，记录保持一致。
7. 打开「开机自动启动」后重启电脑，GoldenPassport 会自动运行。
8. 如果你在用 Bartender、Ice 等菜单栏管理工具，它们能找到并管理 GoldenPassport 的图标。
9. 用一天，看看有没有卡顿、崩溃或者图标消失的情况。

请顺便告诉我你的 macOS 版本，以及 Mac 是 Apple 芯片还是 Intel 芯片：「关于本机」里可以看到。

## 回退

在终端输入 `bash `，把 `rollback.sh` 拖进终端窗口，按回车。脚本会恢复安装前的 App，你原来的记录都还在。

- 回退后，在新版里**新增或修改**的记录，旧版看不到。如果需要保留，回退前先在新版菜单里导出 `.secrets`，回退后再导入旧版。
- 想把数据也完全恢复到安装前，用 `bash rollback.sh --restore-data`。

## 隐私说明

安装脚本和日志只会显示记录的**名称**，不会显示密钥。备份目录 `~/GoldenPassport-backups` 里有你的 MFA 密钥，权限设置为仅你本人可读。测试结束确认不需要回退之后，可以把它删除。
