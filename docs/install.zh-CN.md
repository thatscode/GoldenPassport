# GoldenPassport 0.2.0 安装说明

> [!CAUTION]
> **⚠️ 重要安全提醒：安装会生成一份 MFA 密钥的未加密副本**
>
> 安装脚本会把你当前的 App 和数据完整备份到 **`~/GoldenPassport-backups/`**，里面有你**所有账号的 MFA 密钥，没有加密**。任何拿到这个目录的人，都能生成你所有账号的验证码。
>
> - **不要**复制、上传、打包发给别人，包括求助时发给维护者；
> - **不要**把它放进 iCloud、网盘或者其他同步目录，也不要用任何会上传到云端的备份工具备份它；
> - 确认新版使用正常、不需要回退之后，**请用 `cleanup.sh` 删除**（见下文「清理」）；
> - 「导出」生成的 `.secrets`、`.txt` 文件同样是明文密钥，用完也请删除。

GoldenPassport 0.2.0 针对新版 macOS 从头重写：Apple Silicon 原生运行，也支持 Intel 芯片，需要 macOS 13 或更高版本。从 0.1.x 升级时，已有的账号会自动迁移，旧版数据文件的内容不会被修改，随时可以回退。

## 文件夹里有什么

| 文件 | 用途 |
|---|---|
| `GoldenPassport.app` | App 本身 |
| `install.sh` | 安装或升级，会先备份，并核对迁移结果 |
| `rollback.sh` | 恢复安装前的 App |
| `cleanup.sh` | 确认不再回退后，删除安装备份和 0.1.x 的数据文件 |
| `安装说明.md` / `INSTALL.md` | 本说明的中文版和英文版 |
| `LICENSE` | MIT 协议 |

## 安装或升级

1. 打开「终端」，输入 `bash `（注意后面有一个空格），把这个文件夹里的 `install.sh` 拖进终端窗口，按回车。
2. 安装脚本会依次：
   1. 检查安装包是否完整，以及是否支持你的 Mac 和系统版本；
   2. 把当前的 App 和数据备份到 `~/GoldenPassport-backups/<时间>/`；
   3. 退出正在运行的旧版，把新版安装到「应用程序」；
   4. 从 0.1.x 升级时迁移账号，并和 `gp.secrets` 逐条核对，过程中只显示账号名称。**如果有任何一条不一致，会自动恢复到安装前的 App 和数据**；
   5. 启动 GoldenPassport。

全新安装、从 0.1.x 升级、从 0.2.0 内测版升级，都用同样的方法。从内测版升级时，账号保持不变。

也可以自己把 `GoldenPassport.app` 拖进「应用程序」：首次启动时会自动迁移数据，但没有备份，也没有迁移核对。

## 安装后需要知道的变化

- **界面语言**默认跟随系统。想固定为简体中文或英文：在菜单「语言 / Language」里选择，再按提示点「立即重启」。
- **全局快捷键默认是 ⌃⌥⌘0–9**（0.1.x 是 ⇧⌘0–9，其中 3/4/5 和系统截图冲突）。可以在菜单「全局快捷键（自动填入第 1–10 条）」里切换回 ⇧⌘。
- **自动填入验证码需要「辅助功能」权限，升级后要重新授权**：系统设置 → 隐私与安全性 → 辅助功能。如果列表里已经有 GoldenPassport，但按快捷键不会自动填入，先用「−」把它删掉，再到菜单里重新选一次快捷键，系统就会重新请求授权。没授权时，按快捷键会把验证码复制到剪贴板。
- **全新安装时 HTTP 接口默认关闭**。它没有访问密码，开启期间，这台 Mac 上以你的身份运行的任何程序都能读取全部验证码。从 0.1.x 升级的用户保持原来的设置。如果你用过 beta.3 之前的内测版，又没有在里面改过「启动时同时开启 HTTP 服务」，升级后 HTTP 服务不会再随 App 启动；需要的话，在菜单「HTTP 接口」里重新勾选。
- **平时不联网**：只有点「检查更新…」或者打开「每天自动检查更新」（默认关闭）时，GoldenPassport 才会访问 GitHub。

## 回退

在终端输入 `bash `，把 `rollback.sh` 拖进窗口，按回车。脚本会恢复安装前的 App，数据保持不变。

- **回到 0.1.x**：原来的 `gp.secrets` 从未被修改过，所以 0.1.x 能看到原来的全部账号。在 0.2.0 里新增或修改的账号，0.1.x 看不到。如果要保留，回退前先在 0.2.0 里导出 `.secrets` 备份文件，回退后再导入 0.1.x，然后删除导出的文件。
- **回到 0.2.0 内测版**：它读取的是同一个 `accounts.json`，所有账号保持不变。
- **回到更早的版本**：不加参数时，`rollback.sh` 使用最新的一份备份，也就是这次安装之前的版本。如果先装过内测版、又装了正式版，想直接回到 0.1.x，就要指定最早的那份备份：输入 `bash `，把 `rollback.sh` 拖进窗口，再输入一个空格，然后在 Finder 里打开 `~/GoldenPassport-backups/`，把时间最早的那个文件夹也拖进窗口，按回车。
- 执行 `bash rollback.sh --restore-data` 会把整个数据目录也恢复到安装前，安装之后做的改动会丢失。

回退之后在 0.1.x 里新增或修改的账号，再次升级时不会丢：GoldenPassport 会列出 0.1.x 新增、修改和删除的账号，由你选择要导入哪些。它不会覆盖或删除新版里已有的账号；在 0.1.x 里改过 URL 的账号，会以「名称 (0.1.x)」导入，和原来的账号并存。

## 清理

确认 0.2.0 使用正常、不再需要回退后，在终端输入 `bash `，把 `cleanup.sh` 拖进窗口，按回车。脚本会先确认 `accounts.json` 读取正常，再列出要删除的内容，输入 `yes` 后才会删除。清理之后就不能再回退到 0.1.x 了，新版的使用不受影响。

下面这些文件里都有密钥：

| 位置 | 内容 | 处理建议 |
|---|---|---|
| `~/GoldenPassport-backups/` | 每次安装前的 App 和数据 | **删除**（`cleanup.sh` 会处理） |
| `~/Library/Application Support/GoldenPassport/accounts.json` | 新版正在使用的数据 | 保留 |
| `~/Library/Application Support/GoldenPassport/gp.secrets` | 0.1.x 的数据文件，留着用于回退。在新版里删除的账号，这里**仍然存在** | 确定不再回到 0.1.x 后删除（`cleanup.sh` 会处理） |
| 你导出的 `.secrets` / `.txt` 文件 | 明文密钥 | 用完删除 |

`cleanup.sh` 同时会删除 0.1.x 的 `config.plist`，以及只记录账号名称和 URL 指纹、不含密钥的 `legacy-baseline.json`。删除之前，如果新版的账号比 `gp.secrets` 里的少，或者回退期间在 0.1.x 里改过的账号还没有导入，脚本会先提醒你：它们的密钥只存在于要删除的这些文件里。

新版会把数据目录和 0.1.x 数据文件的权限收紧为仅本人可读（0.1.x 的文件本机所有用户都能读），文件内容不变。

## 求助与反馈

- 完整文档：<https://github.com/thatscode/GoldenPassport/blob/modernize/README.zh-CN.md>
- 遇到问题或有疑问：到 [Issues](https://github.com/thatscode/GoldenPassport/issues) 里反馈。安装、回退、清理脚本只显示账号名称，不显示密钥，可以直接附上终端输出。**不要附带数据文件、备份或导出文件**，里面有你的密钥。
- 安全问题：请不要公开提 issue，而是通过 [Report a vulnerability](https://github.com/thatscode/GoldenPassport/security/advisories/new) 私下告诉维护者。
